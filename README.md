# FREEON

배리어프리 통합 플랫폼 시제품 (정적 사이트 · GitHub Pages)

## 폴더 구성
- `index.html` : 사이트 본체 (사진 포함)
- `facilities.json` : 전국 배리어프리 시설 데이터
- `events.json` : 행사 데이터 (행사 장소는 지도에도 표시)

## 카카오 지도 키
`index.html`에서 `여기에_키_붙여넣기`를 카카오 **JavaScript 키**로 바꿔 주세요.
카카오 개발자 콘솔 > 플랫폼 > Web에 사이트 주소(`https://아이디.github.io`)도 등록해야 지도가 보여요.

## 체험 방법 (한 대의 노트북에서 여러 사람이 체험)
- 회원가입, 글, 댓글, 좋아요, 시설 리뷰는 이 노트북의 브라우저에 저장돼요. 계정이 달라도 같은 브라우저면 앞사람이 남긴 글과 리뷰가 보여요.
- 다음 사람이 올 때는 이름 버튼(우측 위) > 로그아웃 후 새로 회원가입하면 돼요.
- 항상 같은 주소로 접속하세요. 주소가 다르면 (예: localhost와 github.io) 저장 공간이 따로예요.
- 체험 데이터를 모두 지우려면: 브라우저 설정 > 사이트 데이터 삭제 (또는 개발자도구 > Application > Local Storage 삭제)
